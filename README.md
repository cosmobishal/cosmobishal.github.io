# Bishal Neupane Portfolio

A GitHub Pages ready portfolio for astronomy, physics, research and science education.

## Design direction

The site uses a dark observatory aesthetic with orbital motion, subtle star fields, glass panels, monospace research labels and restrained purple and cyan accents.

The aim is to make the site feel closer to a scientific notebook or small observatory interface than a conventional personal profile.

## GitHub Pages

1. Create a repository named `cosmobishal.github.io` or any repository you want to publish with GitHub Pages.
2. Upload the contents of this folder.
3. Open repository settings and enable GitHub Pages from the main branch.
4. The site is static and does not require a build step.

## Content updates

Most personal content lives in `data/site-data.js`.

Update research records, experience, milestones, links and writing ideas there.
